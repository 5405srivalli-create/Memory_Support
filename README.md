# Memory Support

An AI-powered customer support agent with persistent memory using Hindsight.

## Features

- AI-powered customer support
- Persistent memory
- Context-aware responses
- Relevant memory retrieval
- Streamlit interface

## Tech Stack

- Python
- Streamlit
- Hindsight
- AI/LLM

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
